Inter variable font, normal style, weight 100–900, licensed under SIL OFL 1.1 (see OFL.txt).

The seven unmodified WOFF2 subsets were already cached by this project's Next 14.2.35 Google Inter loader in `.next-dev-web/static/media/`. The CSS preserves those exact subsets, Unicode ranges and fallback metrics. Keeping these build inputs in source removes the build-time request to Google Fonts without changing the app's font or theme variable.
